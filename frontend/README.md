# Frontend

Next.js (App Router) + Tailwind CSS. Deployed to Vercel.

## Planned screens (Phase 4)

| Screen | Contents |
|---|---|
| Auth | Register / login, with access-token refresh handled transparently |
| Dashboard | Resume status, extracted skill profile, editable |
| Jobs | Add a job description; list of match-score cards |
| Match detail | Score breakdown: skills matched vs. missing |
| Learning path | Visual rendering of the recommended path through the skill graph |
| Skill gap | Radar chart comparing current profile against target role |

## Status

Empty. The frontend is deliberately built **last**, in Phase 4, against an API that is already
finished, tested, and deployed. Building UI against a moving API wastes rework.
